# Conference Planner

A session booking application for conference attendees.

## Setup

### Prerequisites
- JDK 21
- Docker and Docker Compose

### Build and run with Docker Compose
```bash
docker compose -p exercise5 up --build -d
```

### Check container status
```bash
docker compose -p exercise5 ps
```

### View logs
```bash
docker compose -p exercise5 logs app
```

### Clean up
```bash
docker compose -p exercise5 down -v
```
