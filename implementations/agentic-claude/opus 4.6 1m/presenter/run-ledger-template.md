## Column Definitions

- **Tool/Model/Version**: e.g. "Claude Code / Opus 4 / 2026-09"
- **Prompt**: Summary of the prompt given (not the full text)
- **Workspace Hash**: SHA-256 of `MANIFEST.txt` from the exported exercise
- **Active Human Time**: Wall-clock time the human spent actively steering
- **Elapsed Time**: Total wall-clock time from start to acceptance
- **Interventions**: Number of times the human corrected, re-prompted, or manually edited
- **Usage Charge**: API/token cost if known
- **Acceptance**: PASS / FAIL / PARTIAL — did the result meet the exercise's acceptance criteria?
