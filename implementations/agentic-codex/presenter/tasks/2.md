# Exercise 2 — Debugging

An attendee reports that Practical Kotlin sometimes shows 21 active bookings although its capacity is 20, after Alice and Bob book at the same time. Investigate and correct the issue while preserving duplicate-attendee protection, request replay, cancellation and error semantics. The app must also work when two app processes share one database.

Use the separately supplied evidence bundle. Explain the cause and show that your correction prevents overbooking under concurrent requests. Run the existing checks. Any test coordination must have deadlines and must not block a correctly serialized implementation indefinitely.
