# Exercise 4 — Review

Review the candidate confirmation retry change. This is a review exercise: report findings with evidence and line references, without editing application code. `review/base/ConfirmationDispatcher.kt` contains the base version; `review/change.diff` is the candidate diff; the running source contains the candidate.

Gateway contract: delivery may time out **after** the message has been durably accepted. The gateway deduplicates using the supplied delivery key. Caller rollback cannot undo gateway acceptance. Pending confirmations are retried later, including after restart.

Assess correctness and failure handling against this contract. Explain any scenario that supports a finding and its impact on the attendee. Do not assume a timeout means rejection.
