# Exercise 5 — DevOps

The Java process starts but Compose reports the application as unhealthy. Inspect the app, container logs and health-check configuration, correct the problem, and demonstrate recovery locally. Validate readiness rather than relying only on a running process.

Use a new isolated Compose project name such as `conference-ex5-YOURNAME` and unused loopback ports. All data is disposable. Limit stop/recreate/remove operations to this exercise's containers and volumes. Preserve existing containers, including other exercises. No production or remote deployment is involved.
